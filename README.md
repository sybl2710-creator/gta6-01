# Velvet Tide

Velvet Tide is an original open-world crime story set in Costa Aurelia, a sunlit
coastal city of marinas, palm-lined boulevards and bad money. You arrive with a
debt, a burner phone and no car, and take work from Marisol Vane across three
missions while the police keep asking questions.

Explore on foot or by car. Traffic and pedestrians fill the streets, cars can be
stolen, and wanted levels bring a police response. Combat, a minimap HUD and a
save system are included. All names, story, art and sound are original; nothing
is taken from Rockstar Games.

## Run

Open `game/index.html` in a desktop browser. Or, from the repo root:

```bash
node serve.ts
```

Then open http://localhost:8080.

## Controls

- **WASD** — move / drive
- **Mouse** — look
- **Click** — punch / shoot
- **E** — steal or leave a car
- **Shift** — sprint
- **Space** — jump / handbrake
- **R** — reload
- **M** — mute
- **Esc** — pause
